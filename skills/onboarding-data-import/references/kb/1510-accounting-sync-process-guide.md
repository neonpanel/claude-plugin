# Accounting Sync Process Guide

Category: accounting · Article 1510 · Updated 2026-07-21

## Understanding Sync vs Export

Sync vs Export:
- Sync: Two-way data exchange that keeps systems in real-time alignment
- Export: One-way data transfer that creates a snapshot at a specific time

When to use sync: When you need continuous data consistency between systems
When to use export: When you need a one-time data transfer or backup

## Sync Timing Best Practices

Recommended sync timing:
- Daily syncs for high-volume transactions
- Weekly syncs for stable accounting data
- Real-time syncs for critical financial operations

Avoid syncing during peak business hours to prevent system overload

## Sync Job Management

Key sync job components:
- Connection: The link between your accounting system and Michael AI
- Sync Job: The scheduled or manual process of data exchange
- Ledger Snapshot: A point-in-time record of your financial data

Monitor sync jobs in the dashboard for status and error tracking
