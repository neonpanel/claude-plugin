# Users

Category: NeonAdmin · Article 846 · Updated 2026-02-25

In this article, you will learn how to manage your users in NeonPanel via NeonAdmin.

## Introduction

As your team changes and your business develops, you will need to add, remove or edit user profiles to your account. In this article, we will go through how to manage Users in NeonAdmin.

This is the tab in NeonAdmin where you can add new users, delete those who no longer need access, or edit profiles & reassign roles.

Only Admin and SuperAdmin roles can access NeonAdmin. Read more about roles and permissions.

If you are setting up for the first time, read our article Setting Up: Companies and Users.

## Adding New Users

As your team grows, you will need to add new users to your NeonPanel account. In order to do that, click on the Create User button in the top right hand of your screen.

Once a new user's profile opens up, you will need to enter the Name and Email of your colleague. At this point, you may define user roles immediately or defer this to a later time by editing their profile. Then scroll down and click Create User at the bottom right of the page.

Once the user has been created, the invitation with a link to the login page will be sent to the specified e-mail. Upon the initial login, the user can edit his/her name, and create a password.

## Editing Users

If you want to change a user's role or profile picture, you can edit user profiles by clicking the Edit button on the Users tab in NeonAdmin.

A familiar user profile page will be opened, where you can make relevant changes.

## Deleting Users

If somebody leaves your team, it is best to delete their user profile. In order to do this, on the Users page in NeonAdmin, click on the Delete button.

Once you delete a user, all information associated with that profile will be deleted. Proceed with caution.
