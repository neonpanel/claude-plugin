# How to add your API keys to NeonaSphera

Category: How-To · Article 1555 · Updated 2026-06-29

Helping customers set their API keys

## Overview

1. From any page in the platform, click your avatar in the bottom left corner: ![image](images/img_799cc44f715242409e08d285c480794e.png)
2. In the menu that opens, click: My Model Access -- ![image](images/img_a3cb46791f714691b1093dbbdd408269.png)
3. In the next menu, chose a provider with whom you have API keys, and set the key there ![image](images/img_b28bb9fe8ac647889f6d7569e7f8f4fd.png)
4. Or shown in the image above, users could choose Managed Access, and pay for tokens via NeonaSphera, and we will pass the tokens on to our model provider (OpenRouter) 'at cost', meaning we won't take any markup on the requests.
