# Register

Category: Accounting · Article 1324 · Updated 2026-02-25

The Register Page in NeonPanel lists all Journal Entries ready for sync to accounting software, showing document basis, value, document ID, and sync status. Users can open linked documents in external software and view detailed entry information in popups.

## Introduction

The Register Page in NeonPanel is a central hub for managing and reviewing all Journal Entries (JEs) created by the platform, ready to be synced to a client's accounting software. This page provides essential insights into the financial transactions managed within NeonPanel, offering users a comprehensive view of their accounting data.

## 1. Overview of Journal Entries

The Register Page displays a list of all Journal Entries generated by NeonPanel. Key details include:

Document Basis: Each Journal Entry is linked to the original document it is based on, such as invoices or bills. This helps users trace back transactions to their source documents.

Overall Value: The page shows the total monetary value of each Journal Entry, allowing users to quickly assess the financial impact of transactions.

Document ID: The corresponding document ID in the accounting software is displayed, facilitating easy reference and verification.

Sync Status: Users can see the current synchronization status of each Journal Entry, indicating whether it has been successfully synced with the client's accounting software.

## 2. Interactive Functionality

The Register Page offers interactive features to enhance user experience and streamline accounting processes:

Transaction ID Links: Clicking on the transaction ID of the accounting software will open the document in that software, provided the user has appropriate access. This feature allows for seamless navigation between NeonPanel and external accounting systems.
