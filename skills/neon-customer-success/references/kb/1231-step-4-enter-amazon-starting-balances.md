# Step 4: Enter Amazon Starting Balances

Category: Initial Setup · Article 1231 · Updated 2026-02-25

This article guides users through importing starting inventory balances and associated landed costs for Amazon warehouses into NeonPanel, ensuring accurate data migration and inventory management.

## Introduction

In this step, you will import the starting inventory balances for all your Amazon warehouses. This ensures that NeonPanel has accurate data for inventory management and financial reporting. The process leverages NeonPanel's integration with Amazon to pull necessary information directly from your Amazon account.

## Purpose and Next Steps

By completing this step, you enable NeonPanel to accurately calculate transactions from the Start Date, ensuring seamless inventory and financial management.

## Process Overview

Open the FBA Starting Inventory Data Report: Access the report via this link: FBA Starting Inventory Data Report

Download the Export PO Tab: Download the table as a CSV file from the Export tab.

Review and Verify Data: Ensure all quantity data is accurate and provide the landed costs in the 'price' column.

Upload the Completed Template: Re-upload the completed CSV file back into NeonPanel.

## 1. Open the FBA Starting Inventory Data Report

Access the report by navigating to the following link: FBA Starting Inventory Data Report

## 2. Download the Export PO Tab

Navigate to the Export tab within the report.

Download the table as a CSV file.

## 3. Review and Verify Data

Open the downloaded CSV file.

Review the quantity data to ensure it is accurate.

Provide the landed costs in the 'price' column for each SKU. For Amazon balances, we recommend including the full cost, which encompasses both manufacturing costs and landed costs. You can calculate these using the weighted average cost or by using the last available full landed costs.

## Key Fields in the Template:

Date Order Received: This field specifies when transactions are created. For the migration process, use the chosen Start Date (yyyy-mm-dd format).

Price: Enter the landed costs, including manufacturing price, freight, brokerage, customs duties, and any other related expenses. For inventory already in Amazon warehouses, include the full landed costs.

## 4. Upload the Completed Template

Save the completed CSV file.

Navigate back to the Setup & Settings page in NeonPanel, then move to the Data Uploads section.

Upload the filled-out template using the provided upload functionality under the Inventory Order section.

By completing Step 4, you ensure that NeonPanel accurately reflects your Amazon warehouse inventory balances. This step, along with the others, provides a comprehensive approach to inventory data migration, ensuring reliable and efficient inventory management from the Start Date onward.
