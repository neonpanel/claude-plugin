# Planning Unit

Category: Contextuals · Article 986 · Updated 2026-02-25

Inventory Planning setting determines the manner in which stock level data is displayed, offering a customizable approach to inventory analysis.

## Introduction

The Planning Unit setting in NeonPanel allows you to customize the presentation of inventory planning data, providing tailored insights that meet your specific needs.

By default, the Planning Unit is set to SKU, which provides more detailed information since each row in the table corresponds to a specific SKU.

Alternatively, you can select Product Family as the Planning Unit. In this case, the graphical and tabular data will be grouped by Product Family, with each row representing an aggregated data of all SKUs in that product family.
